OBJETIVO:
Praticar entrada de dados, operadores aritméticos e estruturas condicionais
criando uma calculadora com as 4 operações básicas.

DESCRIÇÃO:
Programa que pede 2 números e uma operação (1-soma, 2-subtração, 
3-multiplicação, 4-divisão) e mostra o resultado.

INSTRUÇÕES:
1. Salve como calculadora.py
2. Execute: python calculadora.py
3. Digite os números e escolha a operação

EXEMPLO:
Digite o primeiro número: 10
Digite o segundo número: 5
Escolha a operação (1/2/3/4): 3
10.0 * 5.0 = 50.0
