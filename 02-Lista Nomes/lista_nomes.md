OBJETIVO:
Praticar manipulação de listas em Python, incluindo:
- Inserção de dados em lista
- Exibição de todos os elementos
- Contagem de elementos
- Pesquisa de elementos específicos

DESCRIÇÃO:
O programa cadastra 5 nomes em uma lista, exibe todos, mostra quantos 
foram cadastrados e permite pesquisar se um nome específico está na lista.

INSTRUÇÕES:
1. Salve como lista_nomes.py
2. Execute: python lista_nomes.py
3. Digite 5 nomes
4. Faça pesquisas na lista

EXEMPLO:
Digite o 1º nome: Ana
Digite o 2º nome: Bruno
Digite o 3º nome: Carla
Digite o 4º nome: Daniel
Digite o 5º nome: Elisa

Nomes cadastrados: 'Ana', 'Bruno', 'Carla', 'Daniel', 'Elisa'
Total de nomes: 5
Digite um nome para pesquisar: Carla
Carla está na lista!
